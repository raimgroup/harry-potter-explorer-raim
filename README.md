# HP Explorer

Атмосферное веб-приложение по вселенной "Гарри Поттера" с нетипичной концепцией:
вместо обычного каталога персонажей — Распределяющая шляпа проводит пользователя
через магический мир. Пользователь проходит короткий Sorting Quiz, узнаёт свой
факультет, и весь визуальный стиль сайта адаптируется под его цвета. Дальше можно
исследовать факультеты, искать персонажей через стилизованный "заклинание-поиск"
и общаться с ними через AI-чат в стиле переписки совиной почтой.

🔗 **Живая версия:** https://harry-potter-explorer-tan.vercel.app

## Установка и запуск

\`\`\`bash
git clone https://github.com/raimgroup/harry-potter-explorer-raim.git
cd harry-potter-explorer-raim
pnpm install
pnpm dev
\`\`\`

Открыть [http://localhost:3000](http://localhost:3000)

Переменные окружения (создать файл `.env.local` в корне):
\`\`\`
ANTHROPIC_API_KEY=your_key_here
\`\`\`

## Процесс проектирования и разработки

Отправной точкой было классическое ТЗ — каталог персонажей с поиском и
пагинацией. Вместо типового "грид карточек" выбрал нарративный подход:
пользователь сначала проходит Sorting Quiz, и это решение определяет всё
дальнейшее взаимодействие с сайтом — от акцентного цвета интерфейса до
подачи контента.

Визуальный стиль прошёл две итерации. Первая версия использовала текстуру
пергамента и декоративный шрифт — по ощущениям вышло слишком "клипартно"
и не передавало атмосферу вселенной. Вторая версия ориентировалась на
эстетику тизеров Pottermore/Wizarding World: туман, силуэт замка, сдержанная
типографика (Cormorant Garamond) вместо декоративных шрифтов, минимум
визуального шума. Разработка велась итеративно через v0.dev с ручной
корректировкой промптов под конкретные визуальные референсы.

## Информация об уникальных подходах

- **Sorting Quiz как точка входа** — вместо прямого перехода в каталог,
  пользователь сначала "распределяется" (4 вопроса), результат сохраняется
  в localStorage и определяет акцентную палитру всего интерфейса
- **"Заклинание-поиск"** — поле поиска персонажей стилизовано под ввод
  заклинания, а не обычную search bar
- **AI-чат с персонажами** — на карточке персонажа можно задать вопрос,
  ответ генерируется через Anthropic Claude API с системным промптом,
  задающим характер персонажа, подан как "письмо совиной почтой"
- **Проксирование всех внешних вызовов** — обращения к hp-api.onrender.com
  и к Claude API идут исключительно через собственные Next.js API-роуты
  (`app/api/`), ни один внешний сервис не вызывается напрямую с клиента

## Обсуждение компромиссов

- Harry Potter API не поддерживает серверную пагинацию (offset/limit),
  поэтому весь список персонажей загружается один раз через собственный
  API-роут и пагинируется/фильтруется уже на своей стороне
- Ради скорости разработки часть UI-компонентов сгенерирована через v0.dev
  и доработана вручную, а не написана с нуля
- Контекст AI-чата с персонажем ограничен коротким системным промптом
  (без полной истории диалога) — приоритет был на скорость ответа и
  простоту реализации, а не на длинную память диалога
- Анимация тумана на фоне сделана лёгкой (CSS, без тяжёлых видео/canvas),
  чтобы не проседала производительность на мобильных устройствах

## Известные ошибки и проблемы

- Тёмная тема и туманный фон применены полностью на главной странице;
  часть внутренних страниц (каталог, карточка персонажа) могут визуально
  отличаться по степени доработки
- Мобильная адаптация фоновой анимации требует дополнительного тестирования
  на слабых устройствах
- Обработка ошибок при недоступности hp-api.onrender.com или Claude API
  реализована базово (нет расширенных retry/fallback сценариев)

## Почему выбран этот технический стек

**Next.js (App Router)** — фронтенд и серверные API-роуты в одном проекте,
что закрывает требование "все внешние API вызываются с сервера" без
отдельного backend-сервиса, плюс бесплатный автодеплой на Vercel при
каждом push в main.

**TypeScript** — надёжность типов при работе с данными персонажей и
ответами внешних API.

**Tailwind CSS** — быстрая, консистентная стилизация и адаптивная вёрстка
без написания кастомного CSS с нуля.

**Anthropic Claude API** — для AI-чата с персонажами: демонстрирует
прикладную интеграцию LLM в реальный пользовательский сценарий, а не
просто как отдельную "фичу для галочки".

**Vercel** — нулевая стоимость хостинга, автоматический HTTPS, serverless
функции для API-роутов без необходимости отдельно администрировать сервер.
